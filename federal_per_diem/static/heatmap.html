How to read this map

The national view fills each state with a smooth regional gradient that preserves small high-cost areas from its underlying ZIP rates. Search a ZIP or click a state to see the exact value for each ZIP area.

Purple ZIPs intersect multiple official rate localities. They stay out of the gradient because a ZIP alone cannot identify one correct rate.

Boundary names preserve Census terms such as township, borough, CDP, or county subdivision. A rate-area outline appears only when GSA defines the locality as complete counties.
